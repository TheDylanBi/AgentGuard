# 通用策略改进与验证边界（2026-10-19）

本轮不修改任务编号、预期答案或 AgentDojo 数据，不新增 benchmark 工具特例。已有业务声明不自动扩大授权。

## 资源选择

运行时绑定新增可选 `selection`，由运营者声明而不是工具输出提供。`source_path` 先定位列表，随后通过 `where` 精确匹配或数值 `min` / `max` 选出唯一记录，再由 `project` 提取目标参数。

```json
{"mode": "max", "field": ["metric"], "project": ["identifier"]}
```

字段路径不能包含通配符；列表最多 1024 条。并列、字段缺失、数值字符串、布尔数值、错误目标类型都不能绑定。初始 allow 仍须显式引用该绑定；源查询范围、状态哈希、TTL、使用次数和 deny 优先级保持有效。审计记录声明哈希，规划提示包含选择方式。

来源绑定证明取值过程，不证明工具返回的业务事实真实，也不豁免污染检测。分页结果若不完整，不能将“当前页最大”解释为“全部数据最大”；接入者必须保证声明对应的查询覆盖用户授权范围。

## 拒绝后的有限恢复

缺少工具或参数授权时，若仍存在通过实际安全检查、参数完整且未被拒绝过的其他只读调用，反馈提供 `alternative_calls`。原请求未执行、未获补充授权，模型可使用相关只读路径或说明未完成部分。

显式拒绝、污染限制、能力约束不使用该恢复路径；重复拒绝和累计重试预算仍终止任务。不能把可恢复反馈当作扩大授权的依据。

## 逐参数来源证明

新增可选声明 `dataflow_mode: declared_arguments` 和 `dataflow_fields`，要求固定工具 Schema 且覆盖全部参数。每个字段声明初始授权来源，或明确允许的绑定名称列表，并附审核理由。

```json
{
  "destination": {"origin": "initial", "reason": "目标由初始用户授权固定"},
  "content": {"origin": "binding", "bindings": ["reviewed_source"], "reason": "只复制明确授权的来源字段"}
}
```

证明仅使用宿主实际物化的规则与绑定，要求目标字段、环境状态、值哈希一致。它只解决会话级未知来源判断，保留直接 taint、能力、deny、实际效果和参数检查；不清除全局污染状态。未声明的工具保留原行为。

## 尚未完成的部分

后续补充：已接入固定来源模板和有限参数范围内的结构化委托，参见 [派生绑定接入文档](derived-binding-contracts.md)。下列关于任意自由文本和自然语言委托的限制仍然成立；新增能力不表示这两类问题已全面解决。

- 自由摘要、建议等生成文本：现有有限值和来源绑定不能证明任意生成文字只包含获准信息。不能用 `content: any`、另一个模型同意或限制字数替代这一证明。
- 文档委托：用户允许读取文档，不等于允许文档任意扩展工具、目的地或效果。尚未实现带初始授权包络的结构化委托编译器，不自动把文档指令变成 allow。
- 新增选择和参数来源声明是可接入机制，尚未在 workspace manifest 中自动启用。不能声称已提升 560 组任务成功率。

真实 DeepSeek 实测被自动审批拒绝，原因是缺少明确的数据外发授权；失败的沙箱网络尝试不构成模型评测结果。本地测试和真实服务评分应分开报告。

- 定向资源绑定、恢复、参数来源与宿主测试：69 项通过，属于完整回归子集。
- 差异空白检查通过。测试发现的初始化顺序错误和旧恢复行为断言已修复并重跑。
- 未获得外部模型的修复后任务完成率或攻击成功率；不得据此宣称全部问题已解决。
