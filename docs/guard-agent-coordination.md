# 授权反馈与任务执行协作

此改动只完善实验性 review 模式。不生成新的任务权限，不把 CONFIRM 自动改成 ALLOW。

## 受限重规划

review 的规划偏差、目标歧义、证据不足及格式错误先关闭具体调用或语义路径，
不立即因为一次重复就结束所有独立步骤。语义路径由操作、资源类别、效果上界与
resource/destination 参数确定，不以工具名称作为唯一标识。
更换同义工具不能重置已关闭的同一语义路径。该机制不是网络规范化防火墙；
不同编码仍会接受完整的能力、资源、数据流、业务和语义审查。

总拒绝次数上限仍为 6，任务轮次和时间预算继续生效；硬能力边界、业务禁止和污染禁令
继续终止。缺少证据的调用只有在宿主观察发生变化后才可有界重审；新观察不是新权限。

反馈新增 can_continue_task、path_closed、existing_observation_refs 与 policy_expansion_allowed=false。
这些引用不是“所有结果可以任意使用”的授权。没有提前批准的替代路径时，不编造 allowed_next_steps。
控制器仅鼓励原任务范围内的其他步骤，每次调用仍独立审核并复核执行绑定。
已能进入语义审查的生成文本，不再误报成需要从工具原文逐字取得的参数证据。

## 执行记录与一次完成核对

宿主在真实模拟工具执行后记录完整有效动作、前后状态哈希、有限变化路径及原生调用 ID。
状态发生变化、返回未报错但效果未证明、工具报错分别记录。声明的效果上界不冒充已观察效果。
这些记录进入签名审计及 summary；无对应执行不能因为模型自称完成而产生记录。

首次准备结束任务时，pi 与宿主进行一次 checkpoint 握手。行动模型收到原任务约束、
执行记录和拒绝记录，核对遗漏步骤、必要价格/单位/日期以及已完成写入，随后可在剩余预算内
提出必要调用，或准确说明未完成部分。宿主没有自动执行补救，也没有替模型编造地址或默认日期。
成功写入不得因核对而重复执行；所有新调用走同一授权链。第二次准备结束时不再重复核对。

宿主反馈在行动模型上下文中明确标记为控制器数据，不作为新的 benchmark 用户授权；
原始任务及 review 的授权根保持不变。工具文本和参数字符串仍是不可信数据。

**限制：这不是自然语言任务完成性的形式化证明。** 程序能证明执行记录存在，不能只凭状态
变化证明全部子任务满足用户意图。一次核对后，模型仍可能虚报或漏项。因此：

- requested_effect_verified/whole_task_verified 保持 false，不使用模型自称成功生成真值。
- 官方任务成功只由未修改的 AgentDojo utility 判断；没有执行不伪造成功分数。
- Completion Claim Accuracy、False Block Rate 和 Unauthorized Allow Rate 无独立标注时为 null。
- 测试保留了错误模型再次虚报完成、但宿主仍记录无效果的反例。

## 对照与使用

```powershell
$env:ICB_REVIEW_RETRY_THINKING_MODE = 'disabled'  # 仅支持对应协议的服务
& '.\.local-qwen\run-qwen.ps1' -AllSuites -IntentFormat review -ReviewCoordination scoped
```

旧协作流程可通过 `-ReviewCoordination legacy` 做消融；CLI 对应
`--review-coordination scoped|legacy`。旧流程也保留新增的只读执行记录，
但使用原任务级停止逻辑，不发送完成核对。rules、boundary、baseline 不启用新协作。

首次完整验证固定一轮 97 个新协作任务及同配置 97 个 Baseline。
另固定 4 个旧协作任务与 3 个攻击组合，逐任务保存所有轨迹、评分、错误、拒绝、
执行证据和耗时。一次运行不能证明因果或稳定收益，少量攻击结果也不能代表全量 ASR。
代码和配置哈希匹配才允许严格配对，所有未评分任务单独报告，不按防御成功计算。
